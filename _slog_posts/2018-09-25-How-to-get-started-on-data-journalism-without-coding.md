An introductory guide to data journalism that emphasizes asking whether data can help tell a story, without requiring programming skills. The post outlines key questions reporters should ask (What is your central question? Is there data to answer it? How can that data answer it?) and introduces essential data sources that can inform local reporting on communities, economies, and politics.
