title: Track Maine coronavirus trends by ZIP code
date: 2021-12-23
---

Interactive dashboards tracking COVID-19 cases by ZIP code for Maine communities with populations over 2,000, showing sharp increases in cases across most areas of the state even before the first Omicron variant cases were identified. The visualizations reflect weekly ZIP code-level reports from the Maine CDC, with trend charts excluding incomplete weeks to ensure data accuracy.
