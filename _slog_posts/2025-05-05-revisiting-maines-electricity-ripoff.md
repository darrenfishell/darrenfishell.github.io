title: A durable data pipeline for tracking Maine's retail electricity ripoff
date: 2025-05-05
---

A rebuilt data pipeline for tracking Maine's retail electricity market premium, using dlt and dbt to create a DuckDB database that transforms and analyzes electricity pricing data. The project includes a dedicated Observable Framework site with improved visualization performance, replacing the previous Tableau-based frontend with a cleaner, faster interface while maintaining the analytical capabilities of the modern data stack.
